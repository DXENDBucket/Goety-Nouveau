# 末影漫步接入核对（dev.44）

## 原生状态与结束处理

两端固定 Goety 3.2.0／2.5.58.4。效果魔符选中自己或原生判定的友军玩家；不伪造玩家，也不把效果移植为仅隐身。执行实际 EndWalkSpell.SpellResult，生成实际融身入影效果，写入执行者 SEHelper 原生返回位置与维度，发送实际 CULT_SPELL 粒子和 END_WALK 玩家音效包。

原生 PotionEvents 继续处理效果到期、移除、普通目标隐蔽、攻击加成／结束、创建弹射物、交互、方块操作与维度变化。结束时执行者返回自己的原生锚点，原生事件清除 SEHelper 状态；没有新增传送引擎或持续扣费系统。原生仅在相同维度返回坐标的规则不改写。

这是具有原生有限时长的状态效果，不是无限 held-use channel。一次成功应用收取一次来源的聚晶费用；不附加 Core 十秒回退或每秒账单。效果应用后与普通正面状态一样保留原生生命周期，不要求来源一直持书或保持在视野内。

## 角色、参数与事务

返回锚点属于实际玩家执行者。原施法者提供实际法杖、WandUtil 默认参数、附魔和资源账户。原生 Potency 附魔加算；Duration 附魔先按原生规则替换默认 duration 为每级 100 tick，然后 Ars 时间单位再增加 20 tick，避免被后续原生附魔分支覆盖。增强／抑制修改效果等级，最小零。非正、非有限和溢出时长拒绝。

作用者必须为自己或原生友军玩家；其他生物和方块目标拒绝。已有融身入影效果或任何原生返回锚点均不接管，防止重复施放改变初始返回位置。原生回调即使 addEffect 被拒绝也会写锚点，本接入核对实际效果存在后才提交费用；拒绝时清理新建的孤立锚点。创造费用与冷却仍遵守现有共有配置，主动准备与冷却沿用原生聚晶数据。

NativeEndWalkMixin 只在对应回调的同步 scope 内替换实际玩家执行者，并抑制已折入参数的再次附魔读取。原生法杖施法在 scope 外保持原样。

## 验证与限度

命名空间 goety_nouveau_endwalk，两端各四项服务器用例：

1. 实际原生效果等级／时长／隐藏粒子与图标、原生位置／维度、普通怪物目标隐蔽，实际移除事件返回并清理锚点。
2. 真实装备中的附魔聚晶与未附魔友军，比较原生直接施放的参数；来源独立付费、双方锚点独立、重复施放不覆盖，目标返回不干扰来源。
3. 非友军玩家、友军非玩家与方块拒绝；实际 canBeAffected 拒绝不留下锚点／费用；空账户和创造。
4. 实际 LivingEntity.baseTick 驱动短时效果到期，实际弹射物加入世界事件中断；已有无效果锚点也不覆盖。

FakePlayer 网络连接的 teleport 方法是空实现，因此测试玩家只覆写位置传送接口记录原生回调目的地，并覆写 canBeAffected 提供明确拒绝场景；生产运行未改玩家传送或原生事件。测试并不证明真实玩家网络传送、隐蔽渲染、音效与 HUD；这些仍需客户端人工确认。

原生事件仍只在实际发布时执行：Ars 不自动发布 Goety 的 CastingMagicEvent／CastMagicEvent，本次不模拟 Goety held-use 过程。实际原生交互和弹射物事件照常生效。没有重跑历史全量魔符测试。
