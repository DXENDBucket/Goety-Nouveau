# 原生非聚晶能力第二批：0.1.14

新增三种效果魔符、两种弹射物替换；全部为一级魔符。图标引用原模组物品模型，不打包 Goety 素材。模组内仍按已有规则排列：聚晶能力之后放非聚晶能力，同组的弹射物替换放在其他增强之后。

`abilities.<glyph>.preparationTicks` / `cooldownTicks` 可分别调整吟唱与冷却；继续使用原生 Goety 吟唱/冷却提供者和 Conflux 协调，不影响普通原生 Goety 施法。

## 行为

- **狱云**：原生 `HellCloud`，约 5 秒蓄势、5 秒有效降雨。初始半径 1，支持范围、强度、时长修饰；延时只改变降雨寿命，蓄势不随之变长。保留原生云粒子、雨粒子、遮挡检查、伤害与无敌帧。仅本附属生成的云在伤害成功后补齐原生使徒专属的灼烧魔印；不创造隐藏使徒，也不改普通原生云。位置以现有云类适配相同方式放在目标上方并避开顶棚，云保持在生成位置。
- **虚空闪电陷阱**：原生 `VoidLightningTrap`，40 tick 蓄力，保留地面提示、雷击数据包、爆发粒子、虚空之蚀 II 和原生概率魔法火焰。伤害读取 Goety 的末影守望者伤害配置，再加原生强度/Ars 强化。支持范围修饰。生成成功即完成此效果；不等到雷击才继续后面的编排。
- **恶意炸弹**：原生 `IllBomb`。保留重力、弹跳、计时爆炸和盾牌反弹：反弹后的新弹体归格挡者所有，不再扣原施法者资源。原生普通爆炸与烟花分支均保留。初速度采用教父远程投掷的 1.0，反弹继续采用原生 1.5；Ars 加速按既有路径缩放。强度增量加入爆炸/烟花造成的每次伤害，不改爆炸半径与烟花数量。普通弹射物由原生运动驱动，特殊 Ars 形态仍由已有载体路径驱动，不新增一套碰撞/轨迹模型。
- **死亡之箭**：原生 `DeathArrow`，保留箭命中粒子、10 tick 后重力、有限寿命、命中后的无敌帧重置，以及原生装备、下界和巫妖条件。速度采用使徒常规射击的主世界 2.4 / 下界 3.2，强度增加基础箭伤害，Ars 加速仍有效。不无条件赠送使徒阶段性药水箭、暴击或全部装备资格。创建后固定为仅创造可拾取，特别在 Forge 设置所有者后重新应用，避免箭拾取模式被原版重置。
- **狂躁**：直接施加原生 `HysteriaEffect`，基础 45 秒；支持强度与时长修饰，只能作用于自身或友军。同等或更强、剩余时间也足够的已有状态不重复扣费。狂躁 I 提供约 +75% 总近战伤害、+25% 总移速，每秒约损失 10% 最大生命；升级也增加代价。保留原生粒子与属性。Forge 2.5.59.2 对玩家使用伤害调用，Neo 3.2.1/3.2.2 直接改变生命，这一平台差异保留，不额外绕过伤害事件。

## 安全、归属与续接

原始施法者、真正伤害来源与选中的位置/目标分别保留。对本附属创建的区域、炸弹及其烟花补充原始施法者与伤害所有者的友军保护；不改变队伍，也不重写原模组全局友军规则。原生盾牌反弹回来的炸弹按新的原生所有者规则执行，允许反击原施法者。

云和雷阵在原始施法者死亡、移除或离开当前世界后清理；原生寿命仍负责自然结束。弹射物沿用既有 `ExecutionSession` 的费用、寿命、取消与特殊载体清理。爆炸的同步作用域通过 `try/finally` 恢复，烟花保留来源标记；普通 Goety 实例不会被自动赋予标记。

直接伤害弹体对实体仍按实际伤害成功续接；恶意炸弹的烟花分支按实际成功创建延迟载荷续接，不伪造当场伤害。炸弹的盾牌反弹不伪造命中成功；碰撞方块则沿用已有方块命中续接规则。没有资源时不会创建效果实体/状态。持续区域按成功创建收一次费用，狂躁按成功施加收一次费用；本批没有另造持续扣费规则。

死亡之箭的原生下界额外 5% 生命扣除默认封顶 **20 生命/次**，仅限制本附属生成的箭：

```toml
[bossAbilities]
capDeathArrowPercentage = true
deathArrowPercentageCap = 20.0
```

关闭开关保留原生额外扣除值；不改变普通原生死亡之箭，也不取消其装备/环境条件。正数吸血治疗不受此封顶影响。

## AI 提示

两种弹射物声明攻击/敌人提示；狱云与雷阵声明攻击、敌人、位置提示；狂躁声明自身/友军攻击强化提示。狂躁的额外用途检查要求目标超过半血且未有狂躁，避免一般 AI 无意义续费或在低血时主动自杀。提示不改变实际效果的权限判断。
