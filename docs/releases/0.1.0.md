# Goety & Nouveau 0.1.0

The first release without the development suffix, for **Minecraft 1.21.1 / NeoForge** and **Minecraft 1.20.1 / Forge**. This contains the same gameplay implementation as the validated dev.58 build; existing glyph IDs, learning data and configuration remain compatible.

## Addon focus self-casting

- Automatically generate effect glyphs and native Ars Scribe's Table recipes for external Goety `IFocus` items that provide a spell. Craft a generated glyph using its focus and a Source Gem.
- Generated glyphs support **player self-casting only**. Native spells choose their own targets and direction from the player. These are not projectile replacements or remote-origin adaptations.
- Retain native preparation, start/use/result/stop callbacks, cast events, sounds and particles, charging intervals and finite shot counts. Uses the configured Soul Energy or Ars Mana account, with native focus cooldowns and creative-mode bypass.
- Preserve the actual equipped staff's type and data, plus enchantments on a matching equipped focus, inside a temporary per-cast copy. The equipped item is not modified. Addons requiring a specific item in the real main hand, a separate casting controller or custom interaction UI may still need dedicated support.
- Add `native_self.enabled` and `native_self.disabledFocuses` settings. Existing dedicated Goety glyph adaptations are unchanged.

Requires **Ars Conflux 0.1.25 or newer in the 0.1.x series**, Ars Nouveau and Goety. Iron & Nouveau is not required.
