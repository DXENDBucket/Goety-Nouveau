# Goety & Nouveau 0.1.3

- Only discover addon focuses from the actual Minecraft item registry. Custom registries containing item references no longer create invalid extra glyphs and recipes.
- Retain the early/late registration-order fix from 0.1.2, including strict identity checks that do not hide genuine item-ID collisions.
- Verify the combined registration regression on Minecraft 1.21.1 NeoForge and 1.20.1 Forge, including repeated observations and a real Item-valued custom registry.

No new Core requirement, glyph content, recipe ingredients or resource-source gameplay change.
