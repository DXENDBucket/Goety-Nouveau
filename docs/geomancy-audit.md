# Pulverize / Scatter 原生行为核对（dev.41）

固定依赖：NeoForge Goety 3.2.0，Forge Goety 2.5.58.4。两端均使用真正的原生回调与实体；原生配方和地雷渲染资源由 Goety 提供。

## 粉碎

入口为 Ars 方块命中。先检查有效世界坐标、已加载区块和原生 `rightBlock`，再调用原生 `blockResult` / `pulverize`；不另建配方表。方块结果、属性复制、空块结果、逐件掉落与 2001 方块事件保留。

原生地术法杖和 Radius/AOE 仍使用 `BlockFinder.multiBlockBreak` 的原始矩形及其非对称高度规则。在本附属同步作用域内，把助手重新射线得到的命中面换成真实 Ars 命中面。各处理位置在原生配方查询前检查坐标及加载情况。主块不匹配时不会仅靠附近可匹配的块支付并成功。

一个有效的原生配方批次收取一次费用；同名自定义配方如果刻意产生与输入相同的结果，沿用原生成功语义。

## 散射地雷

普通分支调用原生 `SpellResult`：三个真实 `ScatterMine`，保留前/左/右原生相对布局，平移到 Ars 位置；有有效水平传入方向时旋转整个布局。强化影响原生额外伤害，AOE 影响额外半径，时间修饰的一个单位增加一秒原生地雷寿命。原生装备附魔仍由原始施法者提供。

地术法杖分支调用原生 `useSpell` 与 `useParticle`。实际执行者仅为自己或友军生物，位置实时跟随。原生约 103 tick 窗口中每 5 tick 生成一次（相位 0 至 100，共 21 次），保留随机落点、已有地雷时的备用落点、电粒子和随机装载声。这个窗口是执行期，不再额外作为前置吟唱等待。普通分支的原生吟唱仍有效。

沿用 Core 执行会话与现有 Goety 每 20 次成功发射一组的计费：第一个结果付第一组，第二十一枚付下一组。无法支付、执行者离开友军关系或失效时终止新布雷；已经放置的原生地雷继续正常存在。普通地雷到期爆炸，法杖地雷到期消散；20 tick 武装、敌人检测、爆炸伤害和 4 tick 爆炸增长结束都由原生实体处理。

原生 owner 保持原始施法者，因此法杖地雷的原生生物攻击属性取值不会偷偷换成被选中的执行者。持久化 source 与 damage-owner 分别记录；仅在本附属标记的地雷上补充伤害来源及其友军过滤。未标记的原生地雷完全保留原生过滤与归属。

## 验证边界

`goety_nouveau_geomancy` 四个针对本批新增行为的服务器用例：真实原生方块/物品配方，命中面范围；地雷布局、参数、保存读取、友军过滤、敌人触发、实际伤害来源和爆炸/寿命分支；法杖全窗口次数/间隔/两组费用；非法配方、区块、资源、创造和失去友军关系。

Neo Ars `SpellResolver` 在调用效果前会查询方块解析能力，那个上游查询可能加载指定区块。区块边界用例直接检查本附属效果入口，不声称整个原版解析链都避免加载。

双端各四项通过。客户端原生外观、声音与实际网络播放尚需人工观察，服务器测试不能证明渲染结果。
