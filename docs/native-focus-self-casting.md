# 附属聚晶：通用自身施法

从 `0.1.0-dev.58` 开始，观察实际注册的外部 `IFocus` 物品，为能提供非空 `ISpell` 的聚晶生成效果魔符。两个平台都在聚晶真正注册时处理，因此不依赖本模组的物品事件是否排在附属之前。Goety 本体及已有专门适配不会重复生成。

魔符 ID 为 `goety_nouveau:glyph_native/<聚晶 namespace>/<聚晶 path>`，名称沿用聚晶本身的翻译，图标及普通物品模型运行时引用原聚晶，不复制素材。默认是 Tier 1，通过原生 Ars 抄写台使用聚晶＋魔源宝石制作，经验成本 27；各魔符另有正常的 Ars serverconfig。

从 `0.1.2` 起修复早于 Ars 物品事件注册的附属聚晶造成魔符物品重复注册的问题；晚于 Ars 的注册继续支持。魔符 ID、已学记录、配方和配置路径不变，见[注册顺序修复](native-focus-registration-order.md)。

从 `0.1.3` 起只观察真正的 `minecraft:item` 注册表。其他模组将已注册聚晶保存到自定义目录注册表时，不会为目录中的别名再次生成魔符或不存在的聚晶配方，见[注册审计](registration-audit-2026-10-28.md)。

## 触发边界

仅真实玩家自身的实体触发有效，例如 `自身 → 附属聚晶魔符`。弹射物打中别人、固定位置、其他生物和 FakePlayer 不会被转成玩家自身施法。目标与朝向由原法术决定，攻击、原生弹射物和召唤都可以从玩家本体产生；没有给未知弹体安装 Ars 轨迹或命中续接。

通用入口调用原生开始、持续、结果和停止回调及相应 Goety 施法事件，保留原生前置检查、声音、粒子与 NeoForge 的法术伤害类型作用域。`SpellStat` 从玩家原生属性构建，强化／抑制调整威力且最低为零；每次回调取得独立副本，避免回调修改污染下一次基础值。

准备时间由原生 `castDuration`／`IChargingSpell.castUp` 决定，使用 Goety 进度显示与既有移动限制。通用魔符在执行会话内准备，不再叠加一次 Conflux 前置吟唱。`chanting.enabled=false` 和 Conflux 上下文的禁用吟唱策略会跳过等待，但仍向原生回调提供已完成准备的时间。

## 法杖与聚晶修饰

从玩家实际携带的 Goety 法杖复制一个本次施法专用的 ItemStack，保留具体物品类型、属性和附加数据；没有法杖则使用普通黑暗法杖的临时副本。若真实法杖内放着相同聚晶，复制它的附魔及数据；不同聚晶的附魔不会移植到当前聚晶。

在原生回调内，Goety 的公共法杖／聚晶／统计／连发次数查询读取当前施法副本；潜行保持真实玩家的输入。原法术调用 `typeStaff`、`rightStaff`、`WandUtil` 或施法事件的特殊法杖分支因此有机会直接生效。回调结束即恢复查询，不换手、不移动玩家，也不把临时 `Shots` 等数据写回装备。

这并不模拟整个 Item.use：附属若直接强转玩家主手物品、要求真实持续按住某件法杖、自己维护第二阶段选择 UI，或依赖独立的客户端施法器／装备 tick，仍可能需要专门适配。不能仅凭接口承诺所有附属聚晶完全兼容。

## 资源、连发与清理

沿用 `resources.source`，默认为灵魂能量，也可切换 Ars Mana。原生费用与匹配聚晶附魔倍率通过已有 Goety 资源账户结算；不再调用 DarkWand 的整套扣费入口，避免重复付款。原生回调执行前支付首次费用，开始回调及准备期间因此也属于已付费的执行。

普通法术出一次结果。`IChargingSpell` 沿用原生发射间隔与有限连发数；`everCharge` 按原生每二十次结果一组，提前支付下一组，防止空资源无限触发。连续施法最长使用既有 `channels.unboundedDurationTicks`（默认 200 tick）作为本次执行窗口，有限弹匣也受这个窗口约束。它不是要求玩家持续按键的原版法杖操作。

冷却写入原聚晶的 Goety 记录，保留自定义冷却与有限连发的比例冷却。创造模式和 Conflux 禁用冷却策略同时跳过检查、写入与自定义冷却提交。同一玩家同一聚晶运行期间不重复开会话。

结束、前置条件失效、下一组付费失败、死亡、换维度、世界卸载和服务器停止都经 Conflux 会话关闭，调用一次停止回调并清理进度和临时状态。未知回调返回 void，无法通用判断它内部是否真正生成了东西，不能保证每种原生空放都自动退款。

## 配置

`goety_nouveau-server.toml`：

```toml
[native_self]
enabled = true
disabledFocuses = ["some_addon:problematic_focus"]
```

禁用列表阻止对应通用魔符施法，不改动原聚晶与专门适配魔符。保留这些物品的注册 ID，避免服务器／客户端与已有存档发生注册表变化。

## 定向验证入口

- `:runGameTestServer -PnativeSelfTests=true -PgameTestNamespaces=goety_nouveau_native_self`：后注册的测试聚晶、真实 Scribe 配方、法杖修饰和作用域、回调副本、有限连发／持续扣费、无效目标、前置拒绝及 Ars 资源／创造模式。
- `:runClient -PnativeSelfPreview=true`：测试聚晶的源物品模型引用、实际模型烘焙与 GUI 预览；自动截图到 `run/native-focus-preview/screenshots/native-focus-glyphs.png` 后退出。

测试聚晶及界面仅在测试源集，发行包没有测试物品，也不包含被引用的 Goety 素材。第三方附属的每种特殊法杖和独立客户端效果仍需分别验证。
