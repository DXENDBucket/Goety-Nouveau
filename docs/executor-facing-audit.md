# 执行者视角修正（2026-10-31）

吐息粒子/命中/引燃、方块射线、水平偏移、腐化光束、发射推动、自身冲刺及方向回退统一读取执行者视角。水鞭沿已有主人头部朝向执行，仅添加联动来源元数据用于区分原生触手，不新增姿态同步；手臂附着偏移仍按身体位置。冲刺的原有目标/落点选择规则不变。

依赖 Conflux 0.1.47 的 `ExecutionAnchor.viewDirection(Entity)`：使用实时 `getViewVector(1)`，怪物可独立转头而不必同步或修改身体朝向。归属、付款和已有位置/入射方向规则不变。完整横向核对在[共享审计](../../Ars-Conflux/docs/executor-facing-audit.md)。

本批按用户要求只构建、做发行包/原生调用点静态核对，不运行 GameTest、游戏客户端或服务端，不部署共享实例。实机画面、实际战斗和转头动态跟随尚待验证。
