# 放逐原生接入核对（dev.46）

## 原生入口

固定 NeoForge Goety 3.2.0／Forge Goety 2.5.58.4。BanishSpell 是选中敌对实体的控制效果，不是让友军代为执行的移动增益。Ars 编排为「触摸／弹射物等形态 → 放逐」。只接受存活的非旁观生物；拒绝自身、原生友军、创造玩家、其他维度和未加载／越界目标。

调用实际 BanishSpell.conditionsMet。该函数原本通过施法者视线追踪选中对象；仅在本适配的短暂作用域中，把这一次 entityResult 替换为 Ars 实际命中实体。原生生命上限、BANISH_IMMUNE 标签、BanishBlackList、失败音效和 EnderEntity 预检事件保持原样。作用域外的普通法杖仍执行原生视线追踪。

之后调用完整原生 touchResult。原施法者提供 WandUtil 参数、Range 附魔和 Void Staff；目标提供随机数与当前位置。候选循环、原生距离检查、Y 限制、下坐骑、randomTeleport 落地／碰撞／流体检查、实际传送事件、game event 和声音仍由原生处理。没有复制随机传送引擎，也没有把施法者替换为目标。

## 事务与边界

原生 touchResult 不返回成功值。因此仅观察这次原生 randomTeleport 的真实返回值；成功才提交既有 Core 资源事务。取消事件、免疫、全部候选失败均不扣费；创造账户免费。失败搜索仍可能按原生行为让目标下坐骑，这不意味着传送成功。

适配的候选入口额外拒绝非有限坐标、真实世界边界之外和未加载的区块；普通法杖无本作用域时不受此附加守卫影响。范围计算验证正值及整数溢出，保留原生搜索次数与 Void Staff 范围翻倍。未新增 AOE 或自定义强化规律。

## 定向验证

命名空间 goety_nouveau_banish，两端各四项：

1. 原生视线指向超过生命上限的诱饵，Ars 实际选中另一只真实牛；只有后者通过实际 randomTeleport 移动，施法者和诱饵不动，落点无碰撞／不在水中且不造成直接伤害。
2. 普通与 Void Staff 对照完整原生候选坐标和顺序。测试 SearchProbe 仅记录 randomTeleport 并返回失败，用于证明搜索参数／失败计费，不代替第一项的真实落地验证。
3. 实际生命限制、配置黑名单、原生免疫标签、加载器 EnderEntity 取消事件，以及原生 Ender Ground 药水事件处理。猪的免疫标签仅存在于测试资源，发布包不包含此标签。
4. 自身／友军／方块拒绝、无资源不执行、创造免费且实际目标被移动。

只补齐本批验证，不重跑历史目录。服务器测试覆盖实际传送与事件、声音调用沿用原生；客户端视觉、声音听感和多人同步仍需人工检查。原生随机传送本身可能找不到落点，这是保留的失败结果。
