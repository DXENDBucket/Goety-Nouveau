# 水流与棱彩射线（dev.34）

依据固定 NeoForge Goety 3.2.0 / Forge Goety 2.5.58.4 的 WaterJetSpell、PrismaBeamSpell、ISpell、WaterJetRenderer、PrismaBeamRenderer、MiscCapHelper；没有增加 Goety 专用 Core API 或 Iron 依赖。

## 角色与同步

原始施法者提供原生装备、法杖、数值与费用；Ars 实际选中的自己／原生友军提供空间位置和朝向。显式伤害归属另行保留。会话持续验证双方存活、维度、执行者阵营、魔符启用与资源。不是把敌人改成施法者，也不产生替身玩家。

原生两套渲染入口限定玩家并检查使用物品／聚晶，不能直接支持非玩家友军。新增 channel_beam 显示实体同步样式、执行者与目标 ID、相对端点、原生水流速度、开始时间和总时长。实体仅显示，不负责伤害；不能保存，恢复后没有会话即移除。复用原生水流双层贴图／renderJetLayer，棱彩采用原生 guardian 光束顶点方法、旋转体、末端面和蓄力颜色。服务器不修改原生 ClientTarget，客户端不伪造持杖状态；普通 Goety 法杖继续使用其原生入口。

显示起点为真实执行者眼睛，不模拟原生玩家第一人称手持偏移。整段射线包围盒参与可见性判断，世界渲染器统一刷新缓冲区。显示状态随会话关闭立即移除；无资源时实体自身也先停止，避免客户端残留永久显示。

## 水流

每 tick 调用原生 SpellResult：实际原生射线、directDrench、灭火／蜡烛／营火、Burning 沸水分支、深渊法杖 Sapped 和水滴粒子。施法者的 potency／range／burning 装备和法杖分支原样保留；Ars 强化映射 potency，燃烧映射 burning。原生实体检测优先于方块检测的算法保留，不声称修正原生隔墙命中规则。

默认原生持续 100 tick；原生正数时长优先，若用户设为无限则用 channels.unboundedDurationTicks。Ars 时效按现有共同倍率处理。第一下在初次费用交易内真正执行，此后每 20 次脉冲支付原生费用。使用原生水流循环声音。朝向变化时端点与实际命中更新；空资源、移除、失去友军关系或结束移除显示实体。

## 棱彩射线

必须有真正执行者的敌方目标；原生 Mob 目标选择仍是 Mob.getTarget，玩家仍走原生视线。限定当前目标不是施法者／执行者／显式伤害主人／施法者原生友军，并要求执行者无遮挡。

原生目标依赖的蓄力发生在 Ars 命中后，所以此法术跳过命中前准备，避免重复 80 tick 吟唱。它是法术内固有过程，关闭全局准备吟唱并不会去掉这段蓄力。蓄力逐 tick 执行原生 useSpell 的气泡，显示不扣费；结束执行原生魔法伤害与 mobAttack 两次回调，保留原生伤害免疫帧／深渊法杖处理，支付一次原生费用。中断不产生伤害或费用。创造沿用免费账户。

Ars 时效可以改变蓄力总时长，但原生气泡阶段始终保持 0..原生蓄力时长，不能在延长时把 spacing 推成负数导致无限循环。目标变为友军、遮挡、资源不足或执行者关系失效都会取消。实际玩家执行者沿用已有 Goety 移动限制提示；不新增非玩家移动约束。

## 验证与余项

两版各五项定向服务器用例通过：原生真实伤害与显式归属、水流灭火／Burning／Sapped、实时转向和可同步的显示状态、按秒费用／空资源／创造、棱彩蓄力时机／最终一次付款、无效或友军目标／中断清理，以及腐蚀光束回归。最初水流用例沿僵尸眼睛水平发射，越过矮牛；修正测试瞄准，不修改原生碰撞。

服务器用例不能验证实际客户端外观。原生私有绘制入口已核对两版 JAR 签名；第一人称／第三人称、非玩家友军、多人追踪与音效仍需游戏内观察。

区域／持续剩余项：Void Shock、Quaking、Warding、Telekinesis、Shocking、Whirlwind、Flying、Burrowing 等仍需逐项检查原生回调和边界。已有某个效果或弹射物表示不代表其全部持杖交互均已复现。
