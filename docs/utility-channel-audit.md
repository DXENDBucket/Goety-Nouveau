# 念力与钻掘（dev.37）

固定 NeoForge Goety 3.2.0 / Forge Goety 2.5.58.4，核对原生 TelekinesisSpell、BurrowingSpell、ModItems、SoulUsingItemHandler、WandUtil、SEHelper、IFocus 与 IWand。原生聚晶键为 telekinesis_focus、burrowing_focus。

## 共用边界

Ars 效果必须命中自己或 Goety 原生友军作为执行者；原始施法者保留数值、法杖、聚晶附魔与付款。执行者提供位置、朝向、受伤状态和实际动作。正数原生时长优先，无限持杖法术通过 channels.unboundedDurationTicks 映射成默认 200 tick 的有限持续段，Ars 时效缩放基准。

第一次真实回调随触发付费，此后每 20 次结果预付下一组。创造资源豁免，空资源、无效接受者、失去友军关系、移除或自然时限停止。普通 Goety 持杖回调不变，不增加 Goety 专用 Core 接口。

## 念力

原生聚晶保存一个可变 victim，不能由多个 Ars 会话共享。每次持续施法创建独立的真正 TelekinesisSpell，原生 focus 的共享实例不作为会话状态。

原生 findVictim、conditionsMet 与 SpellResult 负责获取目标、伤害中断、距离限制、带缓动和符号钳制的运动、摔落距离、碰墙伤害、力量之环窒息及原生传送门粒子。按原生规则保留黑名单、免疫标签、不可抓取弹射物与大小／生命阈值，不自行修正其原生特殊阈值条件。

原始聚晶 potency 以半级增加力量，保留非整数系数；Ars 增幅添加普通原生 potency。实际执行者的装备不覆盖原始施法者装备。选择不能抓取原始施法者、执行者、显式伤害主人或双方友军；原生 Mob 采用其攻击目标，玩家沿原生视线选择。被抓取者移除、出界、变为友军或执行者受伤时停止。没有目标的激活不付费。

显式 damageOwner 用于原生碰墙／窒息伤害，不改变伤害类型。结束清空会话独有 victim；保留原生释放后的 5 秒聚晶冷却，服从本模组冷却开关与创造豁免。失败、未产生动作的会话不额外施加该冷却。

## 钻掘

原生只有玩家采掘状态，所以仅接受自己或友方玩家。原生 SpellResult 完整负责采掘硬度／工具等级、挖掘速度效果、权限与平台事件、破坏裂纹／声音、真实方块破坏和战利品、经验、精准采集／时运、磁力收集、燃烧熔炼及地卜法杖范围分支。无需在适配器里复制两版不同的工具／事件／配方代码。

实际执行者承担权限、采掘数据、统计和磁力收集；原始施法者承担法杖／聚晶附魔／资源／潜行分支。没有有效方块或无法推进时停止，不凭空收费。进入前拒绝未结束的原生采掘状态。采掘数据由一个会话独占，另一位施法者不能抢占或清空其进度；状态变化使用原生字段，没有第二套玩家采掘存储。

结束时清除自己持有的采掘进度和裂纹。切换到其他原生法术也清理；若原生钻掘法杖已接管，释放租约而保留其新进度。不会同时运行两个写入者，不占用原生法杖的数据。

## 验证边界

六个定向服务器用例覆盖并发抓取隔离、真实牵引与碰撞归属、距离／受伤／友军拒绝、真实挖掘与掉落、权限、采掘写入者互斥、资源中断、创造、地卜范围和燃烧熔炼。另一个独立用例检查原生法杖的两种交接。持续抓取测试使用头盔防止测试僵尸日晒受伤触发原生受伤取消。

原生门户粒子、声音与裂纹的客户端观感仍需人工确认；力量之环、时运／精准采集、磁力、领地保护插件完整组合未做人工穷举。本批不宣称全 Goety 目录完成，余项列于 native-focus-coverage.md。
