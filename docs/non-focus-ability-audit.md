# 非聚晶能力接入（dev.52）

固定 Goety 3.2.0 / Forge 2.5.58.4。新增 11 个魔符，两端共用行为代码。没有修改原版聚晶、菌团、骨锤或酿造的玩法。

数值由 `abilities.<id>.preparationTicks` / `cooldownTicks` 控制，单位 tick，范围 0–72000。原生装备吟唱/冷却缩减和通用灵魂能量折扣沿用已有通路；无聚晶能力不冒充某个原生法杖流派。默认费用来源为灵魂能量，仍可全局切换为 Ars 魔力。创造默认免费并绕过冷却。

四种酿造的普通耗材多数为花等常见物品；加上容量材料、强化、酿制灵魂能量，一锅可分装多瓶。上述冷却用于约束免去制药和消耗品、可重复改变地形的便利，不是假设原版每瓶都需要昂贵材料。

## 目标、原生行为和双端

- 迷惑射弹使用真正的 SnarelingShot，普通飞行速度 0.95；三种菌团使用原生 ThrowableFungus 派生实体，速度 0.75。Ars 控制发射方向，不重复叠加原版投掷随机偏差。特殊载体保留自身轨迹。原生 tick、命中、渲染器和事件继续生效。Snap/Blast 支持燃烧；不扩展其原生固定伤害、范围或狂暴持续时间。
- 原生迷惑射弹命中生成 SnarelingGoop；效果版也生成该实体，保留束缚、减速、动画及结束逻辑，可延长持续时间。
- 狂暴爆散在触发位置执行 BerserkFungus 完整命中流程，保留力量 I、速度 I、反胃 I、原生爆散粒子和音效；范围内不会统一过滤友军。
- 聚敌复用 BoneheadHammer 的牵引方向、MobUtil.pull、引力音效和粒子；只取聚敌能力，不附带原武器近战伤害或附魔攻击。扩散增大牵引范围。
- 叶壳是原生硬化树叶空心球壳，不是生命吸收。荆棘陷阱要求活着的实体目标，沿用地面寻址与方块存活判定；增幅增加柱高。
- 移形换影把范围内生物和掉落物聚集到触发点，可包含施法者和友军；保留传送事件及取消规则。
- 腐蚀沿用原生可破坏方块、方块实体、凋灵免疫、破坏事件、装备磨损及伤害规则；不凭空新增掉落或持续状态。
- 酿造使用 BrewEffects 注册实例及其配置费用；调用真正的 applyBlockEffect / applyEntityEffect。命中采用原版 Splash Brew 粒子包，而不是只有服务端状态变化。位置与实体由 Conflux 施法上下文提供，原始施法者继续作为来源。
- 原生 ThrowableProjectile 运动拦截仅作用于受管且由 Ars 驱动的替换实体；原生物品投掷保持原规则。两端分别定义同步数据 API，Forge 使用正式混淆映射。

普通弹射物发射支付一次，重复载体每次命中支付；效果在真实触发时支付。吟唱和冷却复用共同主动施法通路，无聚晶能力把冷却写到对应真实魔符物品上。后续 Ars / Iron 效果继续使用其自己的支付来源。配方全部加入原生 Ars 抄写台与 JEI 类别，详见 glyph-crafting.md。

## 针对性验证

`goety_nouveau_abilities` 的两个用例覆盖原生酿造方块、聚集、装备磨损、牵引、狂暴、陷阱结束、费用、吟唱、原生冷却键与创造默认；四种新弹射物的普通/环绕转换、完整命中、后续 Ars 效果及重复触发断供。`goety_nouveau_recipes` 核对全部 135 配方和材料，并执行真正的抄写台制作及学习。客户端动画、粒子外观和音效仍需游戏内观察，服务端用例不作为外观验收。

这批在本模组各原生类别中排在聚晶类之后；弹射物替换仍在其他增强之后，类别和跨模组分组不改变。创造标签页将整批排到既有内容之后。
