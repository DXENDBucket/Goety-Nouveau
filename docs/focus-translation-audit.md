# 聚晶与魔符中文名核对（0.1.4）

## 命名规则

直接适配 Goety 聚晶的魔符，使用目标发布 JAR 的 `item.goety.<focus>` 简体中文名，去掉末尾的“聚晶”。聚晶本身的命名优先于按外观或召唤物另取的名字。描述继续解释实际弹体、生物和行为；聚晶名与弹体／生物名不同的情况不强行改为一样。

例如原生聚晶叫“腐烂聚晶”，魔符就叫“腐烂”，说明保留“召唤僵尸仆从”；“头颅”魔符的说明使用其实际召唤物“缠魂飞颅”。

| magic_bolt | 魔法箭 | 魔力束 |

本次修正 77 个聚晶对应名称及 1 个额外能力名称（迷惑射弹 → 迷惑灵射弹），并修正相关描述中的原生生物／弹体术语。

## 核对范围

- `BoltFocus` 与 `EffectFocus` 的实际聚晶字段，共 121 个聚晶对应本地化项，含平台限定条目。
- NeoForge：Goety 3.2.2。
- Forge：Goety 2.5.59.2；没有 Breeze 聚晶，跳过这一个平台不提供的条目，其余 120 项全部核对。
- 两端共有聚晶的中文名称一致，可以保留一份 `common/` 中文资源。
- 自动发现的附属聚晶魔符由 `NativeFocusGlyph.getLocalizationKey()` 直接引用源物品翻译，不存在另外手写一套名字的问题。
- 11 个独立能力不拿配方参考聚晶来改名。例如迷惑灵射弹使用缠绕聚晶作为材料／费用参考，并不应因此叫“缠绕”。其已有原生实体／酿造效果名称另行核对；“聚敌”“狂暴爆散”等独立效果保留本名。
- 燃烧、生命吸收、噬魂三个增强魔符与原生附魔名一致；“延伸”为独立增强名称，未强行套用“范围”等其他附魔名称。

## 验证边界

通过直接读取两个原生发行 JAR 的简体中文 JSON，与枚举中的聚晶 ID 逐项比对，检查名称、缺失键和重复键。沿用 `verifyGlyphLocalization` 检查乱码；打包后再次检查两端 JAR 中的中文资源与修改后的源文件一致。

两端发行包与 0.1.3 逐条目比较，只有简体中文 JSON 和模组版本元数据不同，所有可执行代码保持相同。281 个本地化键与英文资源一一对应，未出现重复键、缺失键或乱码。详细哈希和核对数量见[构建记录](focus-translation-build.json)。

这是文字变更，不启动客户端或 GameTest，也不重跑施法测试。没有修改原生 Goety 文件、英文翻译、Core、魔符 ID、配方或任何施法逻辑。
