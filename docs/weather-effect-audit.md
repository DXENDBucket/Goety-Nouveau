# 雷霆与云层效果审计（dev.17）

固定依赖：NeoForge Goety 3.2.0、Forge Goety 2.5.58.4。以两版实际 JAR 的 ThunderboltSpell、HailSpell、MonsoonSpell、AbstractSpellCloud、HailCloud、MonsoonCloud、SThunderBoltPacket、BlockFinder 为准。上游源码仅帮助寻找候选，不替代固定版本核对。

## 接入边界

三者都是效果魔符，在 Ars 命中处触发，而不是替换一颗弹射物。保持原有分类/提供者分组/一级魔符，没有新增独立吟唱、冷却、生存获取或 Core 专用规则。触发计费继续使用既有事务入口，成功才付一次；无效目标、失败伤害、无空间、零寿命及资源不足不收费。创造免费。

## 雷霆

- 命中生物时使用原生 directShock、配置伤害和倍率、完整 potency 增量、痉挛机会、雷雨增益及风暴法杖的原生 chainLightning；连锁半径为原生 range/4。
- 非风暴法杖保留原生附近避雷针 POI 搜索，雷束转移到避雷针，不对原选中的敌人造成伤害；没有额外虚构让避雷针通电的功能。方块/非生物落点可以产生雷束。
- 使用原生 SThunderBoltPacket，而不是只有伤害或普通细电弧。无名法杖的绿色保留。主雷束发给本维度施法者或终点 128 格内观察者，连锁继续由原生逻辑发送。
- 始端为实际施法者眼部，终点是 Ars 命中、目标体心或原生避雷针位置；不再沿施法者朝向重新寻找目标。装备和费用来自 caster，伤害归属来自 damageOwner。
- 原生视线选取会排除友军；Ars 直接给出目标后仍显式排除施法者、友军和创造/旁观目标。

## 冰雹与季风

- 直接生成完整原生 HailCloud/MonsoonCloud，不以每秒重复一次联动伤害模拟云层。云粒子、落雪/降雨、二十 tick 暖机、范围攻击、原生阵营、头顶遮挡、自然寿命均由原实体处理。
- 默认原生有效寿命一百 tick（五秒），不含一秒暖机。Ars 每个延长/缩短时效单位增减一份基准有效寿命；聚晶附魔按原生 durationLevel+1 乘算。不是把一百 tick 误当成秒，也不是只加一个 tick。
- 原生 potency 与 radius 加算规则保留，radius 仍由原生 setter 限制到最多三十二格。风暴法杖给季风额外一格半径；无名法杖保留绿色雷击。
- 冰雹保留选中的 target；只有霜冻法杖分支会原生跟随/重新寻找目标。季风从原生实现看并不追踪目标，因此保持静止。
- 季风对怕水生物的伤害、随机雷击、避雷针转移、痉挛、风暴连锁和雷雨条件仍是原生实现，不遗漏降雨以外的攻击。冰雹保留实际冰冻伤害及 Freezing 状态。
- 已生成的云层自然持续不追加魔符费用，不为每一阵雨重复扣灵魂。新的 Ars 触发创建新的云层时才再次计费。

## 位置适配与双端

以 Ars 落点为中心向上最多四格。有顶壁则将整个云体放在顶壁下，并按最终半径检查方块碰撞、加载区块、世界边界和建造高度；不足以容纳则失败。不会为了扫描而移走施法者，不在顶壁内生成云。

实体选点和方块选点使用统一的实际命中坐标，避免方块的中心坐标改变侧面命中。自身法术也只是在自身上方生成云，不改变后续效果的施法者。季风出生声在成功生成后发出，避免无效生成时在世界原点播放声音。

入口仅服务端执行。客户端继续使用 Goety 原生同步、云粒子和雷束数据包；没有客户端替身或直接引用 Client 类。Native Monsoon/chainLightning 的内部广播仍保留原版行为，本批没有改依赖 JAR 或全局网络方法。

## 验证范围与余项

聚焦 goety_nouveau_weather 两个真实世界用例：雷霆伤害/归属/原生避雷针/法杖连锁/拒绝伤害/计费，以及云层暖机/真实伤害与冰冻/阵营/追踪/静止/寿命/颜色/放置失败/资源不足/创造免费。不重跑历史目录。客户端实际雷束粗细、雪雨和声效观感仍需人工目视。

箭雨为 EverChargeSpell，不能当作单批箭就算完整；其他弹幕、牵引连接、持续吐息、仆从命令等需要分别审计其会话与停止条件。后续可继续核对其他云层效果及触摸型/位置型聚晶。
